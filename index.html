GreenRead Pro

GreenRead Pro 支持页面

GreenRead Pro（绿读 Pro）是一款利用 iPhone / iPad 的 LiDAR 扫描仪和相机来测量高尔夫果岭倾斜度的辅助测量应用，帮助您更准确地读取推杆线路。

将真实的球与旗（旗杆）的位置对准屏幕后，只需将设备姿态调整到水平，即可在屏幕上显示距离、高低差、Break（弯曲量）、坡度方向和预计滚动线路等信息。

📱 运行环境：
需要配备 LiDAR 扫描仪的设备（如 iPhone 12 Pro 及以上型号、iPad Pro）。
不支持 LiDAR 的设备无法使用倾斜测量功能。

1. 应用结构

您可以通过屏幕底部的标签栏访问各项功能。

标签 内容
倾斜测量 主界面。在相机画面上放置球和旗，然后测量果岭倾斜。
设置 进行测量和显示相关的各项设置。未购买时，部分项目将被固定。

首次启动时会显示“使用前同意事项”。请确认测量精度和使用范围的说明，滚动到最后并点击“同意”后即可开始使用。

2. 倾斜测量的基本操作

主要操作分为“三步”：球位放置 → 旗位放置 → 调整姿态并确认。

步骤 1：放置球位

将真实的球和旗（旗杆）都放到画面中，并将设备对准目标。

在屏幕上按住一点，离按压位置稍远处会出现一个放大圆。

滑动手指，使放大圆中心的十字（＋）与真实球的位置对齐。

松开手指即可完成放置。若设置中开启了“自动切换”，则会自动进入“旗位放置”。

步骤 2：放置旗位

请将真实的球和旗（旗杆）都放到画面中，并将设备对准目标。

在屏幕上按住一点，将放大圆中心的十字（＋）对准真实旗位。

松开手指即可完成放置，并切换到数值显示界面。

💡 提高精度的小技巧：
当设备姿态接近 Y 轴 0° 和 X 轴 45° 时，测量精度会更高。
此外，将球和旗（旗杆）放置在屏幕中央偏黄色中间线附近，也能提升精度。

步骤 3：调整姿态并确认（Hold）

当球和旗都放置完成后，说明区域会切换为姿态调整引导。

X 轴：上下倾斜设备，使左侧的 X 指针接近 0°（红点闪烁）。

Y 轴：左右扭转设备，使下方的 Y 指针接近 0°（红点闪烁）。

当显示的指针全部接近 0° 时，会自动进入 Hold 状态（Auto Hold 开启时）。

3. 测量模式

模式 说明 有效条件
Ball 模式 点击球落点进行放置。 始终有效
Pin 模式 点击旗位进行放置。 球已放置

Pin 按钮在 Ball 未放置前会被禁用（半透明显示）。

4. 测量值的解读

距离（Distance）

这是两点间的 3D 直线距离。将以所设定的距离单位显示（m / cm / yd，默认值为 yd）。

基点是 Ball，表示从 Ball 到测量点（Pin）的距离。

高低差

这是 Ball→Pin 的高低差（cm）。

“＋”表示 Pin 更高（向上打球）；“−”表示 Pin 更低（向下打球）。

Break

这是球会偏转的量（cm）和方向。

H（Hook）表示向左偏，S（Slice）表示向右偏。

偏转量是从 Pin 中心到目标点的距离。

5. 屏幕上的显示元素

当测量完成并被 Hold 后，画面会静止，并显示以下内容：

显示 含义
蓝色虚线 球到旗的直线（基准线）
红色虚线 瞄准方向（出球方向 = 瞄线）
蓝色曲线 预计滚动线路（推杆轨道线）
白色箭头 该位置下坡方向（坡度方向箭头）
下方断面图 球到旗之间高低变化
线路区域 以 Ball→Pin 为中心轴的矩形区域，可设置宽度、边框、透明外部显示等
断面图 屏幕下方横向条形图，Ball 位于左端，Pin 位于右端，按高低差和中心线的上下偏移表示
设备姿态仪表 X / Y 轴的姿态显示

X 仪表（屏幕左侧、大型）：表示设备前后倾斜（上下倾斜方向）。

Y 仪表（屏幕下方、小型）：表示设备左右倾斜（扭转方向）。

当指针接近 0° 时会变为红色（开启闪烁时会闪烁），用于提示水平状态的参考。

屏幕中央细黄色十字线为 X / Y 轴引导线，交叉点（屏幕中心）为仪表原点。

6. Hold 功能

Hold 功能可暂时冻结测量画面，便于查看细节。

Hold 中的行为

  • 画面会保持 Hold 时刻的状态。
  • 相机画面更新、标记追踪、测量值更新、姿态仪表更新都会停止。
  • 新的点击不会触发新的测量。
  • 姿态仪表及相关信息（X / Y 轴倾斜、操作引导、引导线）会被隐藏。

手动 Hold

点击“Hold”按钮即可开始 Hold。Hold 中按钮会变为“重新测量”，再次点击即可解除并重置所有测量值。

Auto Hold

当设置中的“Auto Hold”开启（默认开启）时，满足以下条件将自动进入 Hold：

  • Auto Hold 已开启
  • 球和旗已放置
  • 当前显示的轴仪表倾斜均在 0° 附近范围内

7. 设置

您可以自定义倾斜测量画面的显示和行为。

未购买时，带有“※”的项目将固定为默认值，无法修改；购买全功能版后可解除限制。

7.1 测量

  • 距离单位：m / cm / yd（默认值：yd）
  • ※ 深度平均核：LiDAR 深度平均化范围（3×3 / 5×5 / 7×7）
  • ※ Break 中间计算点数：按球到旗的等分点数计算 Break
  • 球位放置和旗位放置的自动切换：球放置后自动切换至旗位放置模式
  • ※ 定位圆半径 / ※ 圆内放大率：放置时放大圆的设置
  • 左手模式：测量点显示在触摸点右侧

7.2 果岭速度

选择推杆轨道线的 Break 分配所采用的果岭速度（快 / 中 / 慢）。

7.3 显示 / 布局

  • 字体大小：屏幕上测量值和标签的文字大小（小 / 中 / 大）
  • 高尔夫球 / PinFlag：图片显示大小和位置
  • 线路区域：宽度、边框、区域外半透明显示、浓度、箭头位置
  • 坡度方向箭头：箭头强度缩放
  • 线路颜色：基准线、瞄线等颜色（可从预设中选择）

7.4 设备姿态仪表

  • X / Y 仪表显示：各仪表显示 / 隐藏
  • ※ Auto Hold：是否在 0° 附近自动 Hold
  • ※ 操作引导显示：显示设备旋转方式的引导
  • ※ 0° 附近闪烁 / 闪烁周期 / 闪烁占比：闪烁显示的设置
  • ※ 轴反转 / 偏移 / 显示倍率 / 0° 附近范围：指针显示的微调

7.5 数据管理

  • 保存设置数据：将所有设置导出为单个 JSON 文件。
  • 恢复已保存的设置数据：从 JSON 文件恢复设置。
  • 可在不同设备或重装后恢复相同设置（未购买时将显示购买引导）。

7.6 恢复默认设置

点击屏幕最顶部的按钮，可将所有设置恢复为应用默认值（会弹出确认对话框）。

10. 常见问题（FAQ）

Q. 为什么显示“设备不受支持”？

本应用需要配备 LiDAR 扫描仪的设备（如 iPhone 12 Pro 及以上型号、iPad Pro）。不支持 LiDAR 的设备无法使用倾斜测量功能。

Q. 测量值存在误差。

倾斜测量会受到 LiDAR 传感器性能、直射日光、草地湿度、测量距离、设备角度、手抖等多种因素影响，显示值仅供参考。

请尽量保持设备水平，并将球和旗放置在屏幕中央附近，以提高准确性。

Q. 为什么没有自动 Hold？

请确认“Auto Hold”是否开启，以及球和旗是否都已放置完成。

此外，当前显示的轴仪表倾斜值也必须均在 0° 附近范围内。

当指针变红（闪烁）时，请保持该姿势并静止不动。

Q. 设置项无法修改。

未购买时，带有“※”的项目将固定为默认值，无法修改。

购买全功能版后，所有设置项都可修改。

Q. 球或旗的位置发生偏移。

已放置的球在设备移动时，只要仍在屏幕显示范围内，就会跟随真实物体位置移动。

请保持设备姿态不变，并在必要时只调整朝向。

Q. 想在更换设备时保留设置。

可在设置界面的“数据管理”中将设置数据保存为 JSON 文件，并在新设备中使用“恢复已保存的设置数据”进行恢复（仅全功能版支持）。

Q. 可以在比赛中使用吗？

赛制规则和当地规定可能会限制比赛中使用电子设备。

官方比赛中的可使用性，请务必提前确认。
